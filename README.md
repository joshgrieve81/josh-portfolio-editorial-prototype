# Josh Grieve Portfolio Reinterpretation Prototype

A local prototype translating the supplied GPT Image 2.0 collage/editorial mockups into a practical web UI direction using Josh's current Webflow content.

## Files

- `index.html` — single-file browser prototype with embedded CSS/JS and GSAP/ScrollTrigger from CDN.
- `IMPLEMENTATION_PLAN.md` — production handoff plan, animation architecture, build phases, and practical notes.

## Run locally

```bash
cd /root/josh-portfolio-gpt2-reinterpretation
python3 -m http.server 8787
# open http://127.0.0.1:8787/index.html
```

## Notes

This is intentionally a high-fidelity direction prototype, not a production implementation. It preserves the editorial/collage energy while using real semantic sections and live content from `joshgrieve.webflow.io`.
